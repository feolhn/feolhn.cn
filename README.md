# feolhn.cn

Static personal lab dashboard for collecting vibe coding, research, and UI experiments.

## Structure

- `index.html`: app shell
- `styles.css`: layout, shelf UI, theme modes
- `script.js`: project data, filtering, sidebar and theme interactions
- `assets/covers/`: generated square WebP record covers

## Deploy

This project is plain static HTML/CSS/JS and can be deployed directly to Cloudflare Pages.

## Privacy

Do not expose local filesystem paths, usernames, credentials, tokens, private data, or other sensitive information in the UI, source data, or published output.
